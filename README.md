# Antigravity GP

Antigravity GP is a browser based racing circuit studio and 3D driving game. Sketch a track, shape its terrain and facilities, review a simulated lap, then drive the circuit against an AI rival.

## Run locally

Requirements: Node.js 18 or newer and npm (Node.js 20+ recommended).

```bash
npm install
npm run dev
```

Vite prints the local URL in the terminal. To make a production build:

```bash
npm run build
npm run preview
```

## Circuit studio

The builder is organized as three stages, selectable in the top bar or with **1**, **2**, and **3**:

- **Shape** — draw, move, erase, and multi-select control points; tune width, elevation, banking, and runoff; set the start/finish point; and use undo/redo and grid snapping. Start from a circuit preset or upload an image underlay and calibrate its scale to trace a real layout.
- **Dress** — configure circuit style and surface appearance, pit lane, crossings, and venue facilities such as grandstands, pit buildings, paddock areas, marshal posts, barriers, cameras, trees, and sponsor boards.
- **Show** — inspect the simulated speed profile, lap estimate, detected turns, elevation and FIA-style grade; play a 3D flythrough; and export or import circuit files.

The current draft autosaves in the browser and is restored the next time the app opens in that browser. Use JSON export for a portable backup or to move a design to another device.

The viewport supports **2D**, **split 2D/3D**, and **3D** views. Press **V** to cycle them and **?** to open the shortcuts guide. In Shape, **P** selects Draw, **E** selects Edit, **X** selects Erase, and Space-drag pans the canvas.

### Import and export

Show → Export & Share can import:

- Antigravity GP circuit **JSON**
- GPS **GPX** routes
- **KML** lines
- **GeoJSON** LineString and MultiLineString data

GPS coordinates are projected into a local metre-based layout. The longest line is used for multi-line files, and dense routes are reduced to a manageable set of editor points. Imported layouts receive default road width and surface settings, which can be adjusted in Shape. JSON circuits preserve Antigravity-specific facilities and configuration.

Exports include circuit **JSON**, a technical **SVG** blueprint, and a high-resolution **PNG** poster. Simulator packages such as Assetto Corsa or rFactor are not currently generated by this project.

## Drive mode

Launch a circuit from the studio to race in the browser. The game includes a 3D car and circuit scene, keyboard driving controls, selectable historic cars, lap timing and results, an AI competitor with difficulty settings, racing-line guidance, minimap, sound, and chase/cockpit/top-down camera options.

## Circuit presets and attribution

The Spa, Monaco, Suzuka, Monza, Interlagos, and Hungaroring presets use simplified centerlines derived from the public [F1 Circuits GeoJSON dataset](https://github.com/bacinger/f1-circuits). Bathurst and Charlotte Roval use simplified paths from [Global Motorsport Circuits JSON](https://github.com/GameDev-Toolkit/global-motorsport-circuits-json). Their paths are scaled to published lap distances; elevation is authored separately, so these are useful layout references rather than survey-grade or official simulator data. Daytona retains an original hand-authored tri-oval scaled to its published 2.5-mile distance, and the karting preset is an original Antigravity GP layout. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for source and license details.

## Technology

- React, TypeScript, and Vite
- Three.js through React Three Fiber and Drei
- Custom spline geometry, lap estimation, vehicle physics, and AI competitor logic

## Project layout

- `src/components/TrackEditor/` — Shape, Dress, and Show studio panels
- `src/components/Race3D/` — circuit and vehicle rendering, views, and flythrough
- `src/utils/` — spline geometry, analysis, physics, AI, presets, imports, and exports
- `public/` — car and environment assets
- `docs/STUDIO_PLAN.md` — studio architecture and evolution notes

## Notes

Lap times and FIA-style grades are generated estimates for design iteration; they are not official homologation or safety certification. Track designs may be exported as JSON for backup and sharing.
